# N1 design: when is a neighbor's warning worth the time?

Version 1. Exposed deterministic sensitivity study, separate from the frozen C1c and D1 runners. Freeze the following choices before running comparisons. The question is whether a paid, fallible warning can reduce late peer batches without increasing the number of late primary jobs at the same reservation rate. Evaluate ordinary information access separately from any claim about communal behavior.

## Work schedule

One shared processor, four slots, two fictional parties. Primary work is ready at slot 1 and needs two uninterrupted slots. Its published deadline is 2, 3 or 4. The peer has one batch arriving at slot 2, requiring one slot. The peer's actual deadline is 2 if urgent and 4 if routine. All policies know the balanced prevalence, published primary deadline and nominal reliability. Only the evaluator sees actual urgency. The policy may start primary work immediately, reserve slot 2 for the peer, wait one slot, or spend slot 1 obtaining a warning before choosing. Waiting gives no observation. All policies have the same choices, access and costs. Neither wait nor consultation can be used after slot 1. The uninterrupted primary job has first use of the processor unless slot 2 is reserved; the peer otherwise gets its first available slot after arrival. Report actual completions and retain misses even after service.

## Fixed matrix and policies

Cross three primary deadlines, three warning reliabilities (2/4, 3/4, 4/4), two actual urgency states, four equally weighted signal variants per truth, and two equally weighted public coin values independent of all other factors. This gives 144 cells per policy. The warning equals truth for the first k of four variants and reverses it for the others. Do not reveal variant, truth, peer deadline or case ID to the decision function. Reliability describes this constructed table; it is not a measured probability about people.

Run all seven predeclared policies: start immediately, reserve unconditionally, reserve on the public coin, wait then start, always request the peer warning and reserve on an urgent report, selectively request the peer warning, and the same selective rule using a matched instrument. Both selective policies start immediately when the primary deadline is 2, reserve immediately when it is 4, and consult only for deadline 3 with reliability above 2/4. Otherwise they start immediately. The instrument returns the identical observation for the same price. It is an explicit control for source identity, not independent corroboration. No learned policy or optimizing search.

## Analysis

Primary completion time and lateness, peer completion time and lateness, both missed-deadline counts, paid consultation slots, deliberate waits and number of reservations are separate outcomes. Publish all cells without filtering, and stratify by deadline and reliability. The main contrast is always consulting vs reserving on the independent public coin, at deadline 3, where both reserve equally often. Check the uninformative warning as a negative control. Compare selective peer and matched instrument outcomes on every cell. Also report the tight and ample deadline conditions even if consultation looks worse. Completing a job does not erase lateness. No composite score, holdout, population inference, independent participant, or model call. The operator can rewrite the schedules and evidence. An effect in this table does not establish an advantage of governance, testimony as such, or a particular agent architecture in the world.
