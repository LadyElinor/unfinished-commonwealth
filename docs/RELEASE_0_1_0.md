# Release 0.1.0

## Implemented

The initial repository provides the persistent workshop, a five-tick repair and succession demonstration, a proposal-only handoff for external participants, and twelve exposed scripted comparisons. Runtime dependencies are limited to Python's standard library. The source includes an MIT license, contribution guidance, research roadmap, provenance, casebook, trust boundary, and pinned read-only CI workflow.

## Local validation

The initial release passed **46 behavioral tests** on Python 3.12.14. Tests include exact-action approval, stale and expired proposals, revocation, concurrent consumption, transactional rollback, altered historical results, missing records, identity reuse, preserved peer backlog, counterstories, scoped lesson inheritance, and forecast accounting.

The full scripted demonstration replays through **24 journal events**, including genesis. It records five ticks, one missed peer deadline, five completed peer jobs, no remaining peer backlog, and a successor's successful application of the scoped quality-flags practice. The original loss remains recorded.

All twelve comparison runs replay locally. The single controller, coached controller, and coached-plus-casebook controller have identical environmental outcomes under their authored policies. The extra procedures incur additional command costs. No model calls were made.

Python 3.11, 3.12, and 3.13 on Linux and Python 3.12 on Windows are configured in CI. Configuration is not evidence that remote jobs have run. Local package building is also checked; this does not establish behavior on every platform.

## Boundaries

This is a local research seed with no external authority, production credential isolation, model-provider adapter, real participant authentication, independent testimony, or implemented integration with the three reference repositories. It does not establish an intelligent machine civilization.

The JSON handoff supports separately operated participants but leaves authentication and model execution to the operator. Accepted lessons can acquire counterstories; formal lesson revision and retirement remain planned. No new emergency power is introduced.
