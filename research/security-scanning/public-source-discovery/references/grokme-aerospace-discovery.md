# Grok.me aerospace discovery

1. Frame the question separately for publisher, subject and platform. Search official showcases, creator posts and indexed maker directories for public project descriptions with SpaceX, Starship, Falcon, orbital mechanics or robotics terms. Record the exact query and inspection date. Follow only explicitly shared demo links. Keep any reported exposure in a citation to the public investigation.
2. Verify the publisher's link to the named app. Record the listing, credited maker, original announcement, actual deployment host, source repository or release, and license. Mark unverifiable fields unknown. A native headset app, a Bot template and a grok.me website each require their own hosting evidence.
3. Assign attribution by the supporting source. Reserve **official SpaceX engineering** for an official announcement or SpaceX-controlled repository explicitly connecting that project to the engineering program. Use **employee demo** when a personal demonstration and the reported affiliation are supported. Use **independent themed project** for a maker-credited project, and **official platform showcase** for Grok's own examples. Preserve **unresolved** when evidence is insufficient. Record corporate relationships separately from product ownership.
4. Grade the evidence per dimension. For physical fidelity record the strongest of *description, visible inputs and units, independent reference check, empirical validation*. For reproducibility record *listing, interface inspected, versioned source inspected, independent replay*. For source availability distinguish a public interface, readable code and licensed reuse. For project fit name the exact behavior to carry over and one measurable acceptance condition. Use *unknown* or *inapplicable* where appropriate. Keep source URLs, revision or artifact digest, observation and remaining uncertainty together.
5. Report bounded negatives. If a search returned no confirmed Falcon project, name the search scope. Retain named false positives only when they help future searches disambiguate a term. Never turn a hostname, an employee's title, a logo, or a game score into a finding of ownership or physical validity.
