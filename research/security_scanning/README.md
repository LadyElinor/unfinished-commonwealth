# Synthetic authorization benchmark

Offline reference model for the GhostShares-inspired public-access, cross-team authorization and simulated robotics approval scenarios.

Run: `python -m unittest research.security_scanning.test_authorization -v`

All records are synthetic. No third-party application is probed and no robot command is issued. These tests validate this model's intended behavior, **not** any real-world vulnerability, deployment security, CORTAC compatibility, or independent reproduction.
